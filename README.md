# MIMPRIME Reference Style Website

Este pacote foi ajustado para seguir o visual do screenshot de referência:
- mesmas cores principais
- mesma linguagem visual
- logo extraído do screenshot
- imagens de serviços extraídas do screenshot
- navegação completa
- páginas internas
- formulário de orçamento que abre no WhatsApp

## Abrir no VS Code
1. Extraia a pasta.
2. Abra a pasta `MIMPRIME-REFERENCE-STYLE` no VS Code.
3. Clique com o botão direito em `index.html`.
4. Escolha **Open with Live Server**.
